### 🔍 CodeAutopsy

**CodeAutopsy** is a developer-focused project aimed at making debugging and understanding code easier.

Instead of simply telling you that your code has an error, the goal is to help explain:

* 🔎 What went wrong
* 🧠 Why it went wrong
* 📝 Which part of the code caused it
* 💡 How it can be fixed
* 📚 What concept the developer should understand
